# [제품·기능명] 문제 또는 변경 주제 — 발생·작업일

- **문제·변경:** 무엇이 발생하거나 바뀌었는가.
- **영향:** 대상과 확인된 영향 범위.
- **상태:** 당시 복구·적용 상태와 남은 항목. 현재 상태를 재확인했는지 구분한다.

## 원인과 근거

- **관측:** 로그·증상·변경 전 상태.
- **원인:** 확인된 원인과 근거. 가설이면 가설로 적는다.

## 조치

여러 조치가 순차적으로 이루어졌다면 번호 목록을 사용한다. 필요한 변경 전후 설정은 표로 비교한다.

- **변경 내용:** 실제 바꾼 대상과 값.
- **조건·예외:** 적용 범위, 제외한 대상, 남겨둔 설정.
- **추적:** 변경 이슈·커밋·작업 기록과 복구 자료 링크.

## 검증과 후속 작업

- **검증:** 확인한 항목과 실제 결과. 미실행은 미실행으로 표시한다.
- **남은 작업:** 미해결 대상과 후속 조치. 담당자·기한은 근거가 있는 경우에만 적는다.
- **주의:** 같은 조치를 재사용할 때 필요한 환경 조건. 과거 작업 기록을 곧바로 실행 지침으로 단정하지 않는다.
