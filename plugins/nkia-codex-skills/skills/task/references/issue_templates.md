# 작업 유형별 입력 가이드

[creator 작업 유형별 가이드](../../linear-issue-creator/references/issue_templates.md)를 사용한다. 본문·Type·프로젝트·증빙은 [공통 계약](../../../references/issue-contract.md)을 따른다.

부모 Feature의 구체적 요구·제외 범위를 보존하고 독립 실행·검증 가능한 결과로 분해한다. 부모와 하위 이슈의 Type은 각 작업 목적에 따라 별도로 결정한다. 기존 6절 입력은 필요한 내용을 4절에 통합하며 자료를 버리지 않는다.
