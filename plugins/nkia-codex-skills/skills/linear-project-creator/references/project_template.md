# Linear 프로젝트 생성 가이드

프로젝트 description 마크다운 템플릿은 [guideline-ref.md "5.2 프로젝트 템플릿"](../../../references/guideline-ref.md) 참조.

---

## 필수 수집 정보

1. **팀 이름** - Linear 팀 선택 또는 입력
2. **프로젝트 이름** - 프로젝트의 이름
3. **프로젝트 요약** - 한 줄 요약 (최대 255자)
4. **프로젝트 설명** - 프로젝트에 대한 상세 설명
5. **프로젝트 목표** - 달성하려는 주요 목표들

## 선택 정보

6. **우선순위** - No priority(0), Urgent(1), High(2), Medium(3), Low(4) 중 선택
7. **프로젝트 리드** - 프로젝트 리더 이름, 이메일, "me", 또는 비워두기
8. **시작일** - 프로젝트 시작 예정일 (YYYY-MM-DD 형식)
9. **목표일** - 프로젝트 완료 목표일 (YYYY-MM-DD 형식)

## 우선순위 매핑

- No priority → 0
- Urgent → 1
- High → 2
- Medium(또는 Normal) → 3
- Low → 4

## 템플릿 섹션별 가이드

### 1. 목표 (Goal)
프로젝트가 달성하고자 하는 것을 구체적이고 측정 가능하게 기술합니다.

### 2. 성공 기준 (Success Metrics)
"기능 배포"가 아닌 "배포 후 어떤 지표가 좋아져야 하는가"를 정량적/정성적으로 정의합니다.

### 3. 주요 마일스톤 (Milestones)
프로젝트의 핵심 단계를 체크리스트 형태로 작성합니다. 예상 완료 날짜를 함께 기입합니다.

### 4. 리스크 및 대응 (Risks)
예상되는 위험 요소와 대응 방안을 기술합니다.
