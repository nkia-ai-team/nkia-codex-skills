# 대상과 작업 가이드

- **목적:** 이 가이드로 할 수 있는 일과 시작 방법.

## 준비 조건

- **대상:** 적용 환경·버전과 사용자. 관리자 작업이면 구분한다.
- **준비:** 필요한 권한·입력·설정. 실제 자격증명 대신 참조 위치나 입력 변수명을 쓴다.

## 실행 절차

1. 첫 작업의 실행 위치와 동작을 적는다.
2. 다음 작업과 필요한 입력을 적는다. 코드가 있으면 실행용인지 발췌·예시인지 구분한다.
3. 결과를 확인할 방법과 기대 상태를 적는다.

환경에 따라 절차가 달라지면 해당 단계 바로 앞에 조건을 둔다. 코드 전체로 이미 설명한 동작을 장황하게 반복하지 않는다.

## 문제 해결

- **증상:** 사용자가 확인할 수 있는 현상.
- **확인·대응:** 진단 방법과 조건에 맞는 조치. 실제 실행·성공 여부와 구분한다.
- **복구:** 실패 시 복구·중단 기준이 필요한 작업이면 근거가 있는 절차를 적는다. 정보가 없으면 미확인으로 표시한다.

## 관련 자료

세부 설계·운영 담당·원본 절차의 링크 중 필요한 것만 연결한다.
